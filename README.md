# Angel CLI

Un sistema conversacional y de estado estructurado para trabajar con Inteligencias Artificiales de forma determinista y predecible.

## Instalación (Desarrollo)

```bash
pip install -e .
```

## Uso Inicial

En cualquier directorio de tu proyecto, corre:

```bash
angel init
```

Esto copiará las plantillas básicas a `.angel/` en tu repositorio.
